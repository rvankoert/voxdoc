# voxdoc
Voicing the Document

###
Many historical documents contain visual and structural elements such as tables, illustrations, and marginalia,
which automatic text recognition (ATR) software struggles to recognise. Our goal is to develop multimodal AI
models, fine-tuned on Dutch sources, that can describe the visual and structural features of historical documents
and integrate this functionality into Loghi, a widely used, open-source ATR package. Besides improving the quality
and accessibility of historical transcriptions, our project will provide support and share its data, tools, methods, and
models under open licenses, and teach other groups in the Netherlands how to apply these to their own collections.

This is an open science project, meaning that we will develop in the open and provide open code and open data. 

## document formats supported

PageXML will be the officially supported input and output format in order to have the best interoperability with existing ATR/HTR frameworks such as Loghi, Kraken and Transkribus.

The LLM will probably take doclang or Markdown as a format.
